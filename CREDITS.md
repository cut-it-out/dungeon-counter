# Credits

All artwork is made by people and licensed CC0; no AI-generated images are used. Each sprite is a tile cropped unchanged out of the pack's spritesheet (16 px tiles, 1 px margin; multi-tile crops join neighbouring tiles without the margin). The game scales and tints them at runtime.

Licence for every file below: **Creative Commons Zero (CC0 1.0)**, http://creativecommons.org/publicdomain/zero/1.0/, as stated in each pack's `License.txt` (checked 20 October 2026).
