# Sprite candidates (plan step S5a): unused alternatives

The sprites used by the game are one folder up, in `public/assets/`. The files here are the shortlisted alternatives Claude Code didn't pick. They are kept until the clean-up step, where they will be deleted. `_contact-sheet.png` shows the full original shortlist at 6× zoom on Dungeon Ink, including the files that were moved up.

Creator, pack, source tile, URL and licence (CC0) for every file, used or not, are in `CREDITS.md` at the repo root.

| File | Was a candidate for | Why not picked |
|---|---|---|
| `floor-stone.png` | Shop floor | Very light grey; the warm wood floor fits the "adventurer's supply shop" brand direction better |
| `awning-green.png` | Stall awning | Green reads as Potion Jade, which the palette reserves for stock; orange matches the Ember Copper trim |
| `potion-green.png` | Shelf potion | Teal is closer to Potion Jade |
| `potion-orange.png` | Shelf potion | Orange clashes with the stock colour |
| `coin-pile.png` | HUD / sale popup coin | The HUD already uses a CSS coin dot; not needed yet |
